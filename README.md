# 她 · 每一面，都动人。

以所提供视频中的女生为主角，参考 Apple 产品页的排版和滚动节奏，制作的个人影像网站。

## 查看

[打开 GitHub Pages 网站](https://wqrnb.github.io/her-in-motion/)

网站与源码仓库均为公开，无需登录即可浏览。网站由 GitHub Pages 从 `main` 分支根目录发布，更新网站文件并推送后会自动重新发布。

## 页面体验

- 深色开场与棚拍风格主视觉，滚动时人像缓慢放大、标题退场。
- 半透明吸顶导航与页面阅读进度。
- 三张可滑动的大画幅亮点展示，支持触控和方向键。
- 视频画面随滚动推进，配合画幅展开与三段文字切换。
- 光影人像、日常原片、黑白时刻三种展示方式。
- 照片灯箱、前后切换、Esc 关闭，以及原视频播放。
- 手机适配、键盘焦点和减少动态效果支持。

## 本地运行

这是无需构建的静态网站。在本文件所在目录启动 HTTP 服务：

```sh
python -m http.server 4187
```

然后打开 http://localhost:4187 。也可以将本目录作为静态站点部署到支持静态文件的托管平台。

## 文件

- `index.html`：页面结构和文案。
- `style.css`：视觉、手机适配、过渡效果。
- `app.js`：滚动联动、画廊、影片播放、照片灯箱。
- `assets/`：影片、原片截图和创意人像。
- `ASSETS.md`：素材来源和生成说明。

页面使用“她 / Her.”作为展示名称，没有添加未经提供的姓名、职业、经历或联系方式。创意棚拍照片由生成工具根据原视频截图制作；原视频和生活照片保留了真实内容。
